# Firmware Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Firmware for the XIAO ESP32-S3 that deep-sleeps, wakes on the button, plays one random MP3 from the card through the MAX98357A, stops on a second press or at end of file, and sleeps again.

**Architecture:** A PlatformIO project with two environments: `native` for host-side unit tests of the pure-logic libraries (index reading, random pick with history), and `xiao` for the device build. Hardware access (SD, I2S, GPIO, sleep) is isolated in two thin modules that the main state machine calls, so the state machine's decisions are testable on the host with fakes.

**Tech Stack:** PlatformIO, Arduino framework for ESP32-S3, `schreibfaul1/ESP32-audioI2S` for MP3 decode and I2S output, Arduino `SD` (SPI) library, ESP-IDF `Preferences` for the pick history, Unity for tests.

**Spec:** `docs/superpowers/specs/2026-10-25-random-song-button-design.md`, sections "Firmware", "Hardware", "Constraints".

## Global Constraints

- Board: `seeed_xiao_esp32s3`. USB CDC on boot disabled in the device build (`-DARDUINO_USB_CDC_ON_BOOT=0`) so deep-sleep draw is not inflated.
- Pin assignment (author's call, builder may change in `config.h` only):
  - `PIN_BUTTON = 1` (D0, RTC-capable, active low, internal pull-up)
  - `PIN_AMP_ENABLE = 2` (D1, high = amp on)
  - `PIN_SD_CS = 3` (D2); SD on hardware SPI SCK 7, MISO 8, MOSI 9
  - `PIN_I2S_BCLK = 4`, `PIN_I2S_LRC = 5`, `PIN_I2S_DOUT = 6`
- Index format exactly as in the card-prep plan: 32-byte header `SONGBUTTON 1 <count>` space-padded then `\n`; 128-byte records `<filename>\t<title>` space-padded then `\n`; record N at offset `32 + 128 * N`. Songs in `/songs/`, index at `/index.txt`.
- `VOLUME = 17` on the library's 0 to 21 scale (a few steps below max per spec). `STEREO = 0`. Both live at the top of `config.h`.
- Debounce 50 ms. Ignore presses for the first 300 ms after wake.
- Pick history ring: 50 entries, stored in NVS namespace `songbtn`, key `hist`. Re-roll on a hit. Up to 5 re-rolls if the chosen file fails to open, then sleep.
- Any error path ends in deep sleep with the amp disabled. No LEDs, no serial output in release builds (serial allowed behind `-DSONGBTN_DEBUG`).
- Wake-to-first-decoded-sample target: 500 ms. Measured in Task 7, not assumed.

## Review Focus

1. Index header with a count larger than the number of records actually on the card (truncated file) must not read past end of file into garbage; `SongIndex::read` returns false on a short read. Tested in Task 2.
2. A record whose filename field is empty or has no tab must be treated as unreadable, not opened as `/songs/`. Tested in Task 2.
3. With a library of exactly 1 song the 50-entry history must not loop forever re-rolling; the picker caps re-rolls at history size and accepts a repeat. Tested in Task 3.
4. A button held down continuously through wake must not register as a stop after the 300 ms window; the stop requires a release followed by a new press (edge, not level). Tested in Task 4.
5. End of file and a button press arriving in the same loop iteration must result in exactly one sleep, not a sleep followed by a second wake-and-play from a queued press; the state machine clears the press flag when entering `Sleeping`. Tested in Task 4.

## File structure

```
firmware/
  platformio.ini
  include/config.h            pins, VOLUME, STEREO, timing constants
  lib/songindex/songindex.h   SongIndex: parse header, read record N (pure, takes a reader)
  lib/songindex/songindex.cpp

  lib/machine/machine.h       Machine: state transitions (pure, takes an interface of actions)
  lib/machine/machine.cpp
  src/hal_storage.h/.cpp      SD mount, FileReader implementing songindex's reader, index fallback builder
  src/hal_audio.h/.cpp        Audio wrapper: begin, play(path), stop, isRunning, eof flag
  src/hal_power.h/.cpp        amp enable, button read/debounce, deep sleep entry
  src/main.cpp                wires HAL into Machine, loop
  test/test_songindex/test_main.cpp
  test/test_picker/test_main.cpp
  test/test_machine/test_main.cpp
```

  struct IndexReader {               // implemented by hal_storage on device, by a memory fake in tests
    virtual bool readAt(uint32_t offset, uint8_t* buf, size_t len) = 0;  // false on short read

### Task 4: Machine (state machine)

**Files:**
- Create: `firmware/lib/machine/machine.h`, `firmware/lib/machine/machine.cpp`, `firmware/test/test_machine/test_main.cpp`

**Interfaces:**
- Consumes: `SongIndex`, `Picker`, `SongRecord`.
- Produces:
  ```cpp
  struct Actions {                   // implemented by main.cpp over the HAL, faked in tests
    virtual bool storageReady() = 0;                 // card mounted and index loaded (builds fallback index if missing)
    virtual bool indexLoaded(SongIndex& idx) = 0;
    virtual bool indexRead(const SongIndex&, uint32_t n, SongRecord&) = 0;
    virtual bool play(const char* path) = 0;         // false if file cannot be opened
    virtual bool playing() = 0;                      // false once decoder hits EOF
    virtual void stop() = 0;
    virtual void ampEnable(bool) = 0;
    virtual void sleep() = 0;                        // never returns on device
    virtual uint32_t millis() = 0;
    virtual ~Actions() = default;
  };
  enum class State { Booting, Playing, Sleeping };
  class Machine {
   public:
    Machine(Actions& a, Picker& p);
    void onWake();                      // called once from setup(); ends in Playing or Sleeping
    void tick(bool buttonPressedEdge);  // called every loop(); edge = new press after release, already debounced
    State state() const;
  };
  ```
  Behaviour: `onWake` enables amp, checks storage, picks and plays, retrying `indexRead` + `play` up to 5 times on open failure; on any failure `ampEnable(false)` then `sleep()`. `tick` in `Playing`: if `buttonPressedEdge` and `millis() - wakeMillis >= 300` → `ampEnable(false)`, `stop()`, `sleep()`. If `!playing()` → `ampEnable(false)`, `sleep()`. Both in one tick still produce one `sleep()`.

- [ ] **Step 1: Write failing tests** with a `FakeActions` that records a call log:
  - `test_wake_plays_random_song`: log is `[ampEnable(true), play("/songs/0007-x.mp3")]`, state `Playing`.
  - `test_wake_no_card_sleeps`: `storageReady` false → log ends `[ampEnable(false), sleep]`.
  - `test_wake_retries_unopenable_then_sleeps`: `play` returns false 5 times → 5 play calls then sleep.
  - `test_wake_retry_succeeds_on_second`: `play` false then true → `Playing`.
  - `test_press_before_300ms_ignored`.
  - `test_press_after_300ms_stops`: log ends `[ampEnable(false), stop, sleep]`.
  - `test_eof_sleeps`: `playing` returns false → `[ampEnable(false), sleep]`.
  - `test_eof_and_press_same_tick_one_sleep`: exactly one `sleep` in the log.
- [ ] **Step 2: Run, expect compile failure.**
- [ ] **Step 3: Implement `machine.cpp`.**
- [ ] **Step 4: Run full native suite** `pio test -e native` → all PASSED.
- [ ] **Step 5: Commit** — `git commit -am "feat(firmware): play/stop/sleep state machine"`

### Task 5: Hardware abstraction layer

**Files:**
- Create: `firmware/src/hal_storage.h/.cpp`, `firmware/src/hal_audio.h/.cpp`, `firmware/src/hal_power.h/.cpp`

**Interfaces:**
- Consumes: `IndexReader`, `HistoryStore`, `config.h`.
- Produces:
  - `hal_storage`: `bool storageBegin()` (SPI + `SD.begin(PIN_SD_CS)`), `class SdIndexReader : IndexReader` (keeps `/index.txt` open across reads, `seek` + `read`), `bool buildFallbackIndex()` (walks `/songs/`, writes index in the exact format with title = filename stem, returns false if zero MP3s), `class NvsHistoryStore : HistoryStore` (Preferences namespace `songbtn`, key `hist`, blob).
  - `hal_audio`: `void audioBegin()` (`setPinout`, `setVolume(VOLUME)`, mono/stereo per `STEREO`), `bool audioPlay(const char* path)` (`connecttoFS(SD, path)`), `void audioLoop()`, `bool audioRunning()`, `void audioStop()`. Implements the library's `audio_eof_mp3` callback to clear running.
  - `hal_power`: `void ampEnable(bool)` (drives `PIN_AMP_ENABLE`, uses `gpio_hold_en` before sleep so it stays low), `bool buttonPressedEdge()` (debounced, edge-detected, 50 ms), `[[noreturn]] void deepSleep()` (`esp_sleep_enable_ext0_wakeup((gpio_num_t)PIN_BUTTON, 0)`, `esp_deep_sleep_start()`), `uint32_t rngU32()` (`esp_random`).

No host tests for this task; it is verified in Task 6 on hardware. Keep each file under 120 lines so the Task 6 reviewer can read all three.
